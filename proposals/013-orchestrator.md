# 제안 013 · 결론 하나가 뒤집혔을 때 문서를 폐기로 바꾸지 않는다

대상 파일: crew/common/CLAUDE-common.md (공통 규칙 · 쓰기 절)

바꾸기 전 문장:
- 파일을 지우지 않는다. 틀린 것은 상태를 void 로. 찾은 파일은 쓰기 전에 상태를 본다.

바꾼 뒤 문장:
- 파일을 지우지 않는다. 틀린 것은 상태를 void 로. 찾은 파일은 쓰기 전에 상태를 본다.
  결론 하나가 뒤집혔을 뿐 수치가 그대로면 void 가 아니다. 문서는 valid 로 두고,
  어느 결론이 뒤집혔는지 색인의 비고에 적는다. 뒤집은 문서가 대체가 아니라면(supersedes: none)
  뒤집힌 것은 결론이지 문서가 아니다.

이유:
한 회차에서 두 봇이 서로 다른 문맥에 있으면서 같은 자리에 멈췄다. 둘 다 [등급 재평가] 를 붙여
같은 것을 물었다 — 앞선 결론 하나가 뒤집혔는데 그 문서를 폐기로 바꿀 것인가.
머리말 규격의 status 는 valid 와 void 둘뿐이라 "일부만 갱신됨"을 적을 칸이 없다.
두 봇이 각각 스스로 답을 냈고 둘의 답이 같았다(폐기하지 않는다). 답이 같았던 것은 다행이지
규칙이 정해 준 것이 아니다. 다음에는 두 봇의 답이 갈릴 수 있고, 그러면 사람 판정으로 올라간다.
한 봇은 문서를 통째로 void 로 돌려 아직 쓸모 있는 수치를 함께 묻을 수도 있다.
규칙 두 줄로 막을 수 있다.
